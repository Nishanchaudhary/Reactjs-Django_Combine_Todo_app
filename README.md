# Reactjs-Django_Combine_Todo_app

A full-stack To-Do application built using Django and React.js. The application allows users to manage their tasks effectively, with the backend powered by Django REST Framework and the frontend using React.js.

## Features
- User authentication and registration
- Add, edit, delete, and mark tasks as completed
- Real-time updates on task status using React
- Django backend API to handle task data
- Responsive UI design

## Tech Stack
- **Frontend**: React.js, Axios
- **Backend**: Django, Django REST Framework
- **Database**: SQLite (default, can be switched to PostgreSQL, MySQL, etc.)
- **Styling**: CSS, Tailwind CSS

## Usage

- You can add, update, and delete tasks from the frontend.
- Tasks are stored in the Django backend, which exposes an API to handle tasks.
- The Django admin panel is available at `http://127.0.0.1:8000/admin` to view and manage tasks directly from the backend.
